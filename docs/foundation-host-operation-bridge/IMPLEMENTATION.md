# Exact captured host execution and raw ownership

CapturedHostBinding lives internally in XPath.Api. It identifies one actual compiled executable, semantic environment, public session and private profile. QuerySourceSession still owns real neutral-source admission. Public raw operations carry their exact host binding; RequireHost also checks the binding's actual session runtime, so creating a second internal session with the same binding cannot mint ownership. A foreign executable object is rejected before any source-role root getter.

A serialized host-call mode shares the existing operation completion/idle protocol. It acquires no fake IQueryOperationLifetime and cannot expand into optional provider mode; provider mode cannot expand into host mode. Source lifetimes are the actual public snapshot leases already retained by the raw operation. User/provider code runs outside engine state locks. Close revokes guards/new work, while CompleteAsync waits for actual call tails before reverse raw release. Primary and every cleanup error retain object identity and aggregate boundaries. Async raw waits remain separate from cancellation of caller waits.

Each call validates role membership, captures supported data with current exactly-one-owner predicates, obtains authoritative roots, validates their operation-stamped ownership and creates a fresh isolated child. It supplies a fresh closed resource policy. A private frame guards context/role access through the synchronous producer/consumer interval, closes immediately on exit, and cannot replay callbacks after its window. Public Evaluate on an internal host candidate refuses until its explicit host producer is selected. Existing public XPath behavior is unchanged.

CapturedQueryHost is implemented in XQuery and uses its real compiler's frozen prolog/module/namespace capture and evaluator. The single new API friend grant permits this internal composition; no public Func factory or reflection is used. CapturedTransformHost uses the existing frozen stylesheet capture and explicit match/global evaluator. The older private factory reuses the factored capture routine without changing its policy. XSLT's existing friendship is retained. A private upper-host query adapter exercises that lower bridge without adding test friends or public surface.

Effective stylesheet static primitive bindings are copied when the adapter is created and installed into the isolated child before transform execution, overriding same-name dynamic variables. The initial real static-parameter test exposed their absence from the fresh child; the correction is scoped to the new adapter. It does not change ordinary static evaluation or the legacy transform path. Compiler dictionaries and mutable contexts are not retained as execution services.

AH-01 accepts explicit internal positive dynamic-binding and namespace ceilings alongside existing session limits; it selects no new public workload defaults. AH-02/AH-03 must separately specify public supported capture policy and actual facade signatures. Match inputs remain document roots; initial modes, arbitrary initial sequences, streaming, uncaptured resource/schema services and broader typed-host integration are not activated. Returned graphs are borrowed unless the synchronous engine consumer detaches/serializes them; no recursive graph copying or universal closed-object getter guard is promised.

HC10 tests real transformed-output consumption within the host window, frame expiration and actual generic host-call tails holding a real file through close/drain. Public BCAP capture's actual serializer, receipt and final outcome/error orchestration remain AH-03 work. General mid-expression interruption, worker/native ownership and workload budgets remain unqualified. The [scope plan](PLAN.json) preserves the remaining requirements and exact owner/release gates.
