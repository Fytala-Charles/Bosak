# Incoming revised owner forms

Response files in this directory are an unsealed incoming area excluded from the prepared packet manifest; this instruction file is part of the prepared packet. Complete the matching BCAP template, preserve its exact proposal manifest hash and validate it with ../tools/returns.py. Original O1–O4 forms from the previous manifest are not revised BCAP responses.

Arrival and format validity do not authenticate the owner or accept its scope. Core records review decisions separately after inspecting the actual response. Do not overwrite historical returns. No revised response has been supplied by preparation of this packet.
