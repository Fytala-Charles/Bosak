# Endpoint and admission boundary

`SchemaQuerySession.BindAdvisorCandidate` supplies the actual engine-issued public environment and private runtime identity. The adapter captures the selected assessor authority, invokes Bind, checks Kind before Value, accepts only a non-null Supported advisor, and returns no binding for Unsupported. Null, NotFound, Invalid and unknown outcomes refuse. Diagnostics, schema-language and coverage strings are not read to establish trust. Cancellation and session availability are checked after every provider outcome read.

Before using a binding, Core checks the borrowed advisor resource and verifies reference identity of its assessor, public environment and the assessor's captured authority, with session/cancellation/resource checks between getters. Equal descriptors do not authenticate another environment. Exceptions propagate. The adapter never calls Dispose on assessor/advisor objects, even if the supplied implementations happen to implement IDisposable; the public contracts describe borrowed resources and supply no ownership transfer.

`CreateIssuerCandidate` first checks the actual session admission table. The original public input must map to this snapshot's exact private InputAdmission projection, and the snapshot must belong to the binding's runtime. Foreign input/session pairs refuse before advisor callbacks. The source admission is checked before and after issuer creation. No incoming Root, origin Source, component Authority, label or digest is used to infer membership.

The per-admission issuer retains that exact public/private input pair, the endpoint binding and captured authority. Its OwnsTypedValue call passes the original public input to the selected public advisor, together with the optional original assessment. OwnsAssessment establishes non-null original issuance. Originless reads still belong to an actual source admission, not a fabricated source-free snapshot.

The caller retains one issuer for repeated reads of an admission. Creating another issuer does not create another scalar registry: the existing registry requires its exact issuer/authority/scope. The adapter adds no independent input/container cache. A binding retains a managed session availability checker, not an operation checker or resource lease. Neither a retained issuer nor a copied marked value keeps source resources admitted.

`ReadTypedCandidate` requires the actual raw snapshot before invoking issuer/provider logic and uses the already captured public limits. Public compilation, Advisor, ReadTypedValue and VM capture retain their existing boundaries. Candidate binding does not mutate the public session's profile or selected Advisor. An explicit future typed identity descriptor and execution path must be qualified before lifting those guards; ordinary/numeric profiles must keep their current behavior.
