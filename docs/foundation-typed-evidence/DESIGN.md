# Private transport boundary

Every staged scalar entry constructs one marked XdmValue using the existing internal transport representation. The marker is that exact entry; its group retains the immutable plain cell, governing/list shape, declared/selected actual type and optional origin. A concurrent registration winner returns its already committed entries and markers. No additional dictionary, per-read marker allocation or raw-operation checker is retained by resident data. Empty results still retain zero scalar entries.

`QueryRegisteredTypedContainer.GetTransport` first runs the current guarded view checks and returns the staged value for its ordinal. Plain `GetAtomic().Value` remains available as internal retained data. Both remain private implementation machinery. The marked payload preserves exact primitive representation and annotations; no descriptive name establishes authority.

`Operation.ValidateTypedTransport` requires an explicitly selected member snapshot before reading its cache or calling a provider. The registry requires its exact marker owner and the exact entry at the stored ordinal, checks that the group is resident, and compares the transported representation with the original immutable payload using the existing representation-sensitive helper. A genuine marker copied onto another payload or decimal scale refuses. A newly constructed lookalike entry cannot borrow a committed group's registration.

Validation builds a fresh TA-01 reader bound to this raw operation, issuer, public/private input mapping, original optional origin and captured selected authority. It checks authority identity and current container/component ownership, atom count and numeric limits without replaying payload/provenance getters. The whole registered group is revalidated; this helper does not select a numeric operand or grant a source-free construction lifetime. Its returned view expires with the validating operation. Marked data can be revalidated under a later live operation on the same admitted snapshot; it cannot keep that snapshot alive operationally.

Close clears/revokes the registry and leaves actual release attached to the original source/raw ownership. A marker may retain managed objects through its group but acquires no resource lease. Close from a provider membership check prevents delivery while the active raw lease retains the owner; drain completes after raw release. Cancellation refuses current validation while preserving a previously committed complete batch. Existing insertion rollback, warm reuse, quota accounting and no-callback commit controls run unchanged.

Existing VM capture validates its established legacy evidence type and continues to reject the new marker. Public schema Unsupported guards and ordinary/numeric profiles are unchanged. Implicit owner discovery, public provenance observation, arithmetic projection, source-free construction and public adapter activation are excluded. The selected issuer must still attest immutable/version-guarded containers; neither reference identity nor cache presence alone proves current ownership.
