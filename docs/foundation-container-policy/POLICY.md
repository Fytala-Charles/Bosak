# Complete-container boundary

The selected additive operation member is:

```csharp
public SchemaResult<ISchemaTypedValue> ReadTypedContainer(
    SchemaQuerySnapshot snapshot, ISchemaTypedValue value);
```

This member is planned and is absent from current binaries. It returns a complete engine-created borrowed adapter using existing public contracts. Governing type, list flag and ordered per-item declared/selected types and source origin remain separate. The first implementation selects ordinary string/boolean/integer/decimal containers; compatible transport follows as a required slice. No existing scalar behavior changes.

The boundary copies plain atomic payloads and guarded evidence after complete authenticated admission. It does not register scalar markers or persistent container cache groups. This avoids relying on the scalar cache ordinal-zero lookup for empty lists, which have no ordinal-zero entry. Per-call atom/numeric limits bound each materialization; aggregate retained caller outputs need separate budget qualification.

Every new view and cursor is raw-operation borrowed. Metadata/evidence/cursor access checks liveness and current admission; compatible access additionally enters its exact serialized paired proof window. A previously copied plain Value remains usable after expiry while TypeEvidence expires. The adapter has no provider issuance identity and cannot authenticate itself on a round trip. Nil/no-typed-value are not inferred from an empty enumerable.

The complete rules are CT01-CT16 in POLICY.json; CTV01-CTV32 are planned cases, not new executed tests. Existing-route characterization is regression evidence only. The original draft/owner returns are preserved; the selected member still needs final owner/manifest acceptance.

Specification basis: [XDM 3.1, immutable 21 March 2017 Recommendation](https://www.w3.org/TR/2017/REC-xpath-datamodel-31-20170321/), sections 2.5, 2.7.1, 2.7.5, 3.3.1.2 and 5.14. The preserved provider boundary and raw lifetime are explicit Bosak host policy.
