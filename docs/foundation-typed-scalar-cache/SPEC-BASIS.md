No new W3C authentication or later spec draft/erratum is adopted.

Implement only an internal source-admission-associated transactional scalar registry. One retained atomic cell consumes one slot; container/origin identity + ordinal is scoped to exact snapshot/environment/issuer/public input/authority. No independent empty-container cache/index, implicit eviction, bytes budget, evidence attachment or public activation. The registry is lazily created and cannot coexist with the older private scalar association on the same admission, avoiding dual accounting. Existing ordinary/numeric v1-v5 source and schema Unsupported guards remain unchanged.

Stage complete TA-01 data, candidate entries and return/undo bookkeeping before a callback-free lock. Under lock recheck engine-owned raw/session/snapshot closure, cancellation, duplicate winners and wide missing-key counts; ensure actual required dictionary capacity, not the configured ceiling. Reference hashing invokes no caller code. Insert all or roll back only this transaction's missing entries with preallocated bookkeeping. Internal fixed fault points support tests; no provider hook runs inside commit. Dictionary bucket capacity need not shrink after abort, but no logical slot/entry remains reserved.

Completed installation is the linearization point. A subsequent delivery cancellation/revocation can leave a complete batch; closure clears it. Accessors remain bound to the current raw operation and revalidate issuer/container/component ownership and numeric/result quotas. Resident cells never retain the creating raw-operation checker. Warm reads reuse stable internal cell identities under fresh raw guards; originless reads still require a real admitted source. Copied payloads remain plain data and internal registration tokens are not VM schema evidence.
