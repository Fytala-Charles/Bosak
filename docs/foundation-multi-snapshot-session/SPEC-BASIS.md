Implements private same-session multi-snapshot operation lifetime, membership-stamped input capture and guarded XPath/XQuery dispatch under the [composite contract](../foundation-composite-ownership/CONTRACT.md), revision a57fd646, using the primitive delivered in 5665d7af. Language semantics remain those adopted in the [factory basis](../foundation-private-host-factories/SPEC-BASIS.md); this adds host lifetime policy rather than new language semantics. Single-snapshot request reuse remains unchanged. Composite requests deliberately require the identical operation token, as selected in the contract. XSLT composite evaluation explicitly refuses until match/global membership is integrated. Native authority routing and mixed universes are not adopted.
