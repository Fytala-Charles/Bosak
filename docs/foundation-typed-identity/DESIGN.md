# Compiled identity and captured scope

The internal factory admits only `$value`, with surrounding whitespace allowed. Calls, arithmetic, other variable names, parentheses, sequences, resource access and focus expressions refuse at admission. The existing immutable option snapshot policy rejects mutable schema sets/callbacks. The accepted canonical source is compiled by XPath31Expression and evaluated by its VM delegate; positive qualification does not replace evaluation with a direct return helper.

The typed descriptor includes its profile/format, canonical variable name, captured static-context fingerprint, MaxOpenSnapshots, MaxCachedValuesPerSnapshot, MaxTypedValueAtoms, MaxNumericDigits and MaxDecimalScale. The public semantic environment and private runtime remain the same engine-created reference pair presented to the selected assessor. A descriptive fingerprint does not authenticate another session. Namespace source mutations cannot alter the frozen environment; every limit changes the fingerprint.

Only the selected compiled factory grants the private runtime identity capability. Existing constructors default it off; ordinary/numeric profiles retain their prior descriptors and execution routes. The internal candidate operation checks raw/session lifetime, requires an explicit member snapshot and validates its exact registered marked scalar through TA-03. The complete current group, selected advisor/authority/types/origin and supplied limits are rechecked. The context is newly created, contains only `value`, and uses the closed resource policy. No caller resolver, focus, ambient variable graph or implicit owner scan is imported.

After VM execution, Core checks raw availability, validates the returned marker through the same selected snapshot, and requires reference identity with the incoming marker plus exact representation equality. A plain computed result, a changed payload, or another valid registered marker with an equal payload cannot be delivered as identity. Cancellation/close after execution also prevents delivery. Identity preserves provenance; a future arithmetic profile must separately authorize primitive projection and return plain computed results.

The operand is one already issued scalar cell, including a selected member of a list-valued container. This does not flatten the entire container, infer nil/no-value from emptiness, or accept an unmarked sequence as a singleton. Empty/multi-container projection is a separate public activation decision. Stored governing/list and declared/actual/origin metadata are retained by the existing scalar registry, which acquires no additional lease or cache index.

General CaptureInputs and EvaluateAtomic refuse on this capability, including plain strings and source-free input contexts. The public candidate session's ordinary Evaluate cannot bypass the explicit selected-snapshot method. Public CompileXPath assessor binding, public ReadTypedValue, constructors, facts and general new-marker capture remain unavailable. This internal profile name is not a published consumer acceptance or a commitment to a public profile name.

Actual compiled controls cover integers, Boolean, Double/Float, strings/annotations, CLR and exact decimals, wide integers, QName, dateTime and duration, plus copied markers and warm raw reuse. Five trusted evaluator fault probes deliberately substitute outputs or interrupt at evaluator return; they test the runtime guard rather than claiming those delegates are compiled user syntax. Close/cancel, foreign admission, revocation, raw expiry and the existing actual owner release/drain tests remain qualified. Local allocation measurements cover the entire compiled identity operation under a held raw lease, with 100 warmup and 1,000 measured reads; accepted owner latency/retained-memory/native budgets remain separate.

The final candidate measured **23,360 bytes per compiled identity evaluation**, including a fresh context, VM dispatch and pre/post guards, versus **200 bytes per warm metadata read** in its separate fixture. Allocation attribution and reduction remain open performance work before public activation. The local 32,768-byte regression ceiling is not an accepted owner budget.
