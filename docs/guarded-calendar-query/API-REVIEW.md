# Guarded calendar API review

Adds one public factory to SchemaQuerySession: CompileCalendarComparison(expression, limits, assessor, implicitTimezoneMinutes, options, cancellationToken). It freezes an operator/timezone and a unique profile/descriptor without routing through default CompileXPath. No public Core API, value layout or map comparer changes.

The closed regex has a fixed128character input bound and XML whitespace. Unsupported syntax/options refuse before binding. Captured supported static dictionaries are copied. The immutable descriptor includes operator, fixed timezone, static fingerprint and all receiving/admission capacities. Runtime context capture permits exactly left/right and the standard namespaces, absent focus and default ambient services; it reuses the existing closed input capture.

The engine locates exactly one registered member owner per carrier, validates transport and projects the staged plain cell. Selected-authority ownership and same/derived relations prove dateTime/time; dateTimeStamp actual types require timezone and stamp payload labels require corresponding actual stamp derivation. Component Authority and descriptive assessor metadata getters remain poisoned in the public fixture and are never used for proof. Normalized second capacities apply to both exact and legacy projections. The public plain adapter still rejects marked carriers; only validated staged plain cells enter it.

Projection is rechecked before and after exact comparison and around existing callbacks. Late source revocation and cancellation after computation are tested; no result is returned after the failed check. This uses the existing immutable/version-guarded provider and raw lease contract; it does not assert transactional simultaneous validity across arbitrary hostile endpoints. Returned booleans are plain. Original representation-bound carriers and provenance remain unchanged and expire normally.

Complete container adapters and node traversal refuse only in the new profile. Singleton admission, async resource retention and escaped-operation refusal reuse existing machinery. Tests also preserve old typed identity, plain adapter and map/getter guards. Issued schema validity/user facets remain issuer responsibilities, not independent arbitrary-schema validation. No native Schema calendar admission, cross-universe compatibility, C45, registry/tag or signed-pin migration is inferred.
