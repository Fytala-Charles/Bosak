# Open-session drain adoption basis

3 November 2026, recorded before source edits; implementation base baf634f9 / 1.44.1. This slice adopts no new XPath/XDM language semantics. Preserve the exact dated Recommendations and sections in [W1-A adoption](../foundation-w1-neutral-admission/SPEC-BASIS.md). Host lifetime policy follows the accepted immutable QueryFacade.cs.txt and OperationLifetime.cs.txt in [R2 inputs](../foundation-bcap-owner-review/inputs/proposal/QueryFacade.cs.txt), manifest ff475d712f6ef6aa5033113cc39afb887ae4cbad24705098c5c9cb2097641688.

Implement an internal open-session idle observation before public facade promotion. An idle session drains immediately; a busy session waits for its current busy epoch, including source-free work and pending admission/rollback. Observing idle does not close the session or prevent subsequent admissions. Cancellation of a caller's wait must not cancel raw work or release resources. A callback must not await its own busy epoch. Closed-session drain retains its stronger deferred-cleanup completion and error contract. No new public surface, schema authority, native acceptance, API freeze or publication is implied. Patch source version 1.44.2.
