# TA-02: scalar cache and typed-numeric policy

4 November 2026. Core selected the cache-accounting and typed-numeric projection policies for the next internal slice. **Source remains 1.53.0**, baseline `b77727b9`; no TA-02 production registry, typed numeric profile, public schema route or public API change is implemented here. Existing private original-scalar caches remain unchanged. [Policy](POLICY.md) resolves the two TA-01 follow-ups; [implementation checklist](IMPLEMENTATION.md) prepares the internal transactional scalar registry.

The scalar cache ceiling keeps its documented meaning: one retained atomic evidence cell consumes one slot. Multi-atom registrations commit all-or-nothing, repeated identical references reuse their slots, and empty containers get no independent resident cache record. Atomic shape metadata is retained only with nonempty scalar entries. There is no product-of-limits memory budget, silent eviction or plain-value fallback when evidence capacity is exhausted.

A future explicit typed profile will preserve evidence for identity and use a validated primitive projection for numeric computations. It must authenticate current ownership and actual numeric type first; arithmetic/comparison results are plain computed values. Existing plain v1-v5 profiles remain marker-refusing. Schema constructors/casts, source-free construction and provider-owned exact no-op conversion remain separate routes; their existing evidence rules are not replaced by numeric equality.

The reference model passes 12 accounting cases, 1,000 empty-container admissions, four injected rollback points, two explicit interleavings, three cancel/commit/delivery cases, precommit revocation, synthetic numeric-family checks and **1,000 seeded scenarios / 30,000 operations**. These are model checks, not C# concurrency, native allocation-fault or XSD type-derivation qualification. [Results](evidence/MODEL-RESULTS.json) and the executable model are retained.

Fresh unchanged-binary controls pass **231 distinct cases** across reader/association/kernel/transport/public refusals and primitive numeric profiles. A Core observer correction reruns 30 of them (261 total executions); original zero-length process-exit reports and corrected loaded-hash proof are retained in [binding correction](evidence/BINDING-CORRECTION.json).
