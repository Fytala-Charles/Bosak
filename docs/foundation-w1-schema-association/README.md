# W1-B optional original schema association

3 November 2026. Source **1.44.0** adds a qualified internal original-scalar association over [W1-A neutral admission](../foundation-w1-neutral-admission/README.md). Ordinary sources still need no issuer or assessment. [Current status](STATUS.json), [immutable adoption](SPEC-BASIS.md), [33 association controls and 24 ordinary regressions](ACCEPTANCE.json).

## Implemented boundary

`OpenAssessedSnapshot` enters the already-acquired neutral owner, then binds the selected advisor inside an actual raw operation. It requires the identical compiler environment, exact original origin and explicit positive finite registration/cache limit. Binding failure rolls back the host obligation; close during binding or provider getters defers release through raw completion. The advisor remains borrowed and is never disposed by Core.

The internal advisor authenticates original facts by the exact node/facts/input/origin tuple after ordinary membership and exactly-one-operation-owner checks. This slice validates fact association; it does not yet read general fact payloads or implement the full public node-facts channel. A registered preserve-copy can retain original facts while using distinct input nodes/snapshot registrations. A strip-copy remains ordinary and cannot acquire authority from another operation member. Labels or equal-looking fields do not replace owner predicates.

Scalar reads first authenticate the exact issued container/input/origin tuple, then use guarded getters and the existing evidence kernel. Each getter is surrounded by source/advisor/issuance checks, with current type and origin checks before transport is accepted. The bounded cache retains immutable issued evidence; cache hits revalidate issuance/type/origin without re-reading payload getters. Providers must keep issued containers immutable or revoke issuance before change. Original evidence survives supported identity evaluation; computed results retain the existing engine conversion behavior. Captured scalar metadata is revalidated before dispatch and cannot cross to a different admitted snapshot.

The finite registration limit is explicit and enforced before excess payload access. Unissued containers consume no slot. An authenticated but malformed container attempt can occupy a registration slot until close; this bounded internal policy is not a promise of cache eviction or retry. Cancellation remains cooperative at operation/kernel checkpoints, not forced interruption inside a provider getter.
