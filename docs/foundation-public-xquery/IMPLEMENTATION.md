# Captured public XQuery execution

The public compiler lives in Bosak.XQuery.Api.Schema and preserves the reviewed optional compiler/assessor/XML-line-ending/cancellation parameters. Its first selected profile is ordinary XML. Non-null assessor returns Unsupported before provider getters; schema imports refuse through the existing captured-compiler policy. Static/syntax/runtime errors propagate rather than becoming unsupported-feature results. Cancellation is checked before and after synchronous compilation and on live raw boundaries; compilation and a single engine expression have no hard interruption guarantee.

The immutable binding stores the exact compiled executable and its direct instance evaluator, captured environment and shared session. The evaluator must belong to that exact executable; no caller descriptor or same fingerprint grants ownership. Public query dispatch uses the same raw Run/RunAsync membership, host-call serializer, actual source leases and post-cleanup engine liveness checks as AH-01. No new friend or assembly-reference change is needed.

A fresh isolated child copies direct supported primitive variables and admitted node focus/data. Actual context cardinalities set copying ceilings, rechecked by existing capture; callers must not concurrently mutate EvaluationContext during capture. The compiled effective module/static context stays on that uniquely owned child for deferred evaluation. Existing Evaluate/EvaluateIsolatedContext paths retain their restoration behavior. Runtime acquisition is closed; mutable loaders/resolvers, execution gates, arbitrary callbacks and prepopulated engine state are refused by the selected context policy.

Output is empty, an atomic or node, or a flat outer sequence of atomics/nodes. Binary atomics are included. Structured/function/external/JNode and nested sequence cells are not selected. Public entry does not claim the general exact parsing/arithmetic/cast/map-key/serialization pipeline: existing ordinary XQuery numerics remain legacy behavior and NU-01 stays open. The five session limits retain their existing units; they are not a general result-item/time/byte or arithmetic budget for ordinary XQuery.

A private sequence adapter preserves known/unknown length and single-pass markers without materialization. Length, enumerator acquisition, advancement and current access are serialized on the same exact raw operation. Revocation is checked between underlying MoveNext and Current and after each call before delivery. Frame guards are not reused after their window; continuation calls get fresh guarded windows while keeping the original raw operation. Raw completion waits for an actual in-flight deferred call before releasing resources, and cancelled caller waits do not release work.

The existing XdmSequence struct caches Current, so a previously returned scalar or node can remain reachable after a guard closes. Outer source callbacks are protected; returned graph getters are not recursively wrapped. Consume borrowed data inside Run/RunAsync and detach the pieces you retain. Snapshot/input providers retain their own resource and concurrency obligations; no new mandatory enumerator disposal slot or universal cursor-release behavior is promised. A streaming prefix can precede a later query error or unsupported cell.

The immutable language basis is the dated [XQuery 3.1 Recommendation](https://www.w3.org/TR/2017/REC-xquery-31-20170321/), sections 2.1.1, 2.1.2, 2.2.3 and 2.3, as recorded before source edits in ADOPTION.json. Host ownership and profile refusals are explicit engine policy. This is not blanket XQuery/schema/structured-result conformance or final owner/freeze acceptance.
