Static context is established through compilation and prolog/module processing. Capture must precede provider binding. Descriptive fingerprints do not authenticate environments.

Implement private factories for a named bounded profile: XPath 3.1 frozen supported options, XQuery registered immutable module sources/namespaces with effective prolog capture, and principal-source XSLT with primitive static values and copied legacy compiler settings. Reject schema-import/BCL schema configuration, mutable XSLT resolvers/policies/listeners, external stylesheet modules/packages, conditional/shadow static preprocessing and unsupported static values. These are deliberate profile refusals, not general language-conformance decisions. Existing public compilation paths retain their behavior.

Bind an already-owned provider capability only after compilation. Require exact environment identity before reading its issuer; cache the issuer, check binding identity/availability on private access, and borrow rather than dispose the provider. Closed resource policies refuse all wired acquisition routes with no fallback; static attempts refuse compilation even when a function catches the acquisition error. Runtime refusals retain existing function semantics. Independent multi-snapshot ownership, native provider acceptance and broader capture profiles remain pending.
