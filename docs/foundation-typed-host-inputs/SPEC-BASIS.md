# Typed private host input/result adoption

1 November 2026, recorded before source edits. Adopt the bounded data/result profile exercised in [the real private session fixture](../foundation-real-host-session/README.md). Existing immutable language sources remain [XSLT 3.0 REC-xslt-30-20170608](https://www.w3.org/TR/2017/REC-xslt-30-20170608/) sections 2.3.2–2.3.4, 3.5.6 and 10.1.1, with the earlier [production adoption](../foundation-xslt-context-promotion/SPEC-BASIS.md). No ordinary public host semantics change.

Use explicit nonreflective capture of focus, direct scalar/owner-admitted node bindings, namespaces, base URI/default namespaces/collation. Refuse advanced context state, unsupported bindings, invalid focus/counts and non-ordinal custom alias tables. Borrowed nodes require a trusted ownership predicate and stable owner scope; typed data does not issue authority. Add guarded flat atomic visitation inside the actual private operation, with cooperative checks and explicit result limits; it does not detach evidence or recursively guard arbitrary graphs. Empty results visit no items.

Factor the existing XQuery evaluator into an internal EvaluationContext bridge while retaining its public wrapper, and bind direct XQuery/XSLT evaluators in the existing upper XSLT assembly. XSLT binding checks owner-admitted match/global roots before invoking node getters. Preserve close/release behavior and original friend metadata. Reflection remains only in diagnostic/test policy coverage. Bump minor source version to 1.38.0; perform a full production rebuild, unit/gate qualification, public declaration/friend audit and repeated allocation measurement before completion. Public factories, complete effective-context/provider/lifetime capture, exact numerics and C45 acceptance remain outside this step.

Review amendment before final qualification: stamp operation-captured requests with the actual private snapshot and reject unbound or foreign-snapshot requests before host evaluation. Standalone data capture/CreateContext remains an internal data helper without node authority. Reuse across operations is allowed only on the same live snapshot. This closes a cross-snapshot request-reuse gap in the first draft; preliminary receipts remain separate.
