Host issuance, input/environment identity, getter ordering, resource leases and finite limits are Core contract policy, not W3C authentication mechanisms. No later draft/erratum adopted.

Implement an internal uncached reader only. A caller-selected issuer adapter attests exact public/private input mapping, environment, optional origin, authority and immutable/version-guarded issued container membership. Its Owns predicates establish trust before provider getters; incoming handle Authority/name/annotation claims never do. Retain governing type and IsList independently of zero/one/many ordered atomics, per-atomic declared/actual types and optional original assessment. No XDM sequence flattening, evidence attachment, cache registration or public schema activation occurs.

Results/accessor views remain raw-operation guarded; copied primitive payloads are not authenticated transport. Source/advisor revocation is checked around every provider read, including enumerator acquisition/MoveNext/Current. One extra MoveNext may detect an over-limit cell, but its Current must not be read. Dispose is attempted exactly once under retained raw leases even after logical revocation; primary and cleanup failures remain ordered. No partial result is published. No hidden borrowed-owner disposal or retry.

Positive explicit atom/digit limits and nonnegative supplied scale precede reading; numeric Integer/Decimal payload capacity is checked before normalization while separate owned type evidence carries authority. Incoming markers/default cells/non-atomics/foreign components/origins refuse. The immutable/version-guarded container contract permits retained metadata to avoid repeated getters while rechecking ownership; this is not persistent caching. No total-memory, string-byte, latency or hard single-call cancellation promise is introduced.
