# Exact calendar atomic transport contract

25 November 2026. This authorized batch contains twenty interdependent contracts, grouped into one cohesive transport PR, with implementation, commit/push, review and automatic passing merge. [ADOPTION.json](ADOPTION.json) pins normative revisions and exclusions before implementation. No package publication.

Add a private exact calendar payload to XdmValue using existing DateTime/Time kinds, an explicit FromExactCalendar factory, IsExactCalendar indicator and ExactCalendarValue accessor. Derive builtin annotations from the validated calendar family; optional user type annotation is descriptive and grants no authority. Reject uninitialized components. Preserve all fractional digits, timezone presence, extended years, kind and annotations through boxing, sequence storage, private evidence attachment and authenticated typed identity transport.

Existing legacy getters must refuse exact payloads even when a particular value could be narrowed, so old numeric/calendar algorithms cannot accidentally round after conversion. Existing legacy factories/getters retain their behavior. Exact payload ToString uses bounded invariant component text, not canonical UTC serialization. Map comparer refuses exact calendars before any same-key shortcut; instant equality, arithmetic, casts and broader query support need separate adoption.

SchemaTransportMatches compares exact component identity plus existing builtin/user annotations and kind, never stringified milliseconds. A marker from one value cannot authorize another value with changed fractions, timezone presence/offset, annotation or family. Plain values and annotation strings confer no authority. Existing issuer/component/origin membership, snapshot/session lifetime, cancellation, quotas and no-partial-publication rules apply unchanged; exercise actual public SchemaQuerySession reads and identity evaluation. General Schema provider/native dateTime/time/dateTimeStamp admission and C45 remain pending. Do not alter sealed historical packets or published pins.
