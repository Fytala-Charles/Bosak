New exact getters read the complete numeric value. Legacy IntegerValue checks Int64 range; DecimalValue constructs a CLR decimal only when normalized scale <= 28 and coefficient fits 96 bits. No formatted parsing or rounding fallback. Legacy XdmValue.ToString remains a checked legacy-format route: extended numeric representations outside those CLR ranges throw OverflowException; callers use BigIntegerValue for explicit integer formatting or ExactDecimalValue.ToInvariantString with an explicit character bound. This avoids implicit extreme-scale padding. Legacy map keys, arithmetic and other consumers likewise retain checked legacy getters; wide-domain integration is pending. Direct EBV checks actual zero without narrowing. Public CLR Equals remains representation equality, distinct from numeric map-key equivalence.
