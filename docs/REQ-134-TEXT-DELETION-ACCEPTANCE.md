<h1>REQ-134: text deletion acceptance plan</h1>
<p>Planned evidence - 19 October 2026</p>
</div>

**Pending design: 28 planned groups, zero new text-deletion tests executed.** Read the [proposed contract](REQ-134-TEXT-DELETION-CONTRACT.md), [unchanged consumer inquiry](REQ-134-literal-text-instruction-deletion.md) and [design handoff](REQ-134-CONSUMER-DESIGN-HANDOFF.md). Each engine group needs positive and edge/refusal cases. These are coverage groups, not 28 passed tests. Ten existing public inspection/runtime probes are baseline evidence only.

| Group | Area | Required evidence |
|---|---|---|
| TD01 | Authority and ownership | Actual owned imported/inserted/replaced text targets; equal-byte/URI/ID foreign descriptors and targets refuse by reference. Older owner remains usable only on itself, without application-currentness claims. |
| TD02 | Placement and names | First/middle/last/sole instruction under top-level template/LRE chain; alias/default XSLT namespace and explicit 3.0/4.0. Wrong kind, literal text name, root/top-level/non-template parents refuse. |
| TD03 | All proposed spellings | Paired empty, paired ordinary nonempty and self-closing succeed within scope. Full lexical extent is removed, never expanded/repaired; self-closing has null OriginalBodyRange, paired empty has an actual empty body span. |
| TD04 | Payload and syntax proof | Actual zero-or-one ordinary payload covers complete paired body. CDATA including empty, comments/PIs/elements/mixed/split or ambiguous bodies refuse; Kind=Text alone cannot prove syntax. |
| TD05 | Effective controls | Absent/no/false/0 non-expansion and supported local false override; effective expansion/output escaping/invalid controls refuse even for empty/self-closing targets. Attributes are never repaired. |
| TD06 | One complete source edit | Full nonempty original instruction and empty candidate seam; exact prefix/suffix replay equals ExportSource. Payload belongs inside removal; no whitespace/namespace/comment/PI cleanup. |
| TD07 | Empty parent and selection | Last-child deletion retains paired parent spelling; SurvivingParent is actual mapped direct parent. No sibling/payload/Expression selection is fabricated. |
| TD08 | Removed subtree evidence | R contains instruction plus its actual payload only, in preorder: cardinality one for empty/self-closing, two for nonempty including whitespace payload. Attributes/namespaces are metadata, not synthetic removed IDs. |
| TD09 | Complete disjoint partitions | O = R + map domain + merge originals, C = map image + merge destinations, all disjoint/complete; map injective and removed payload excluded. Actual refs, parent/ordered child lists, names and raw/expanded attributes/ranges agree. |
| TD10 | Bounded whitespace coalescence | Zero/one group joining exactly two immediate original ordinary whitespace siblings under mapped parent. Nonempty full original fragments, exact ordered contiguous candidate coverage and actual owned destination; no fragment is a synthetic descriptor. |
| TD11 | Normalization at seam | Physical CR/LF/CRLF seams, tabs and numeric whitespace references in four encodings; engine proves actual joined-run Text without concatenating original parsed values. All lexical fragment bytes remain unchanged. |
| TD12 | Separators and unsupported merges | Comments/PIs/elements keep unrelated nodes separate; one-sided whitespace stays ordinary survivor. Significant text/CDATA, nonadjacent/larger groups, wrong parent or removed payload in fragments refuse. |
| TD13 | Mixed/preserved boundaries | Direct significant parent text/direct CDATA and any surviving ancestor preserve, including nearer default reset, refuse. Default without preserving ancestors and supported local xml:space on removed text are covered. Existing replacement preserved/mixed behavior remains unchanged. |
| TD14 | Malformed authority-boundary evidence | Missing/extra/duplicate/foreign/reordered/gapped/overlapping/partial removals/maps/fragments, incorrect source ranges/value/attributes/parent/destination refuse at engine or consumer boundary. No publicly forgeable snapshot API is added just for tests. |
| TD15 | Encodings and coordinates | UTF-8 BOM/no-BOM, UTF-16 LE/BE matching BOM/declaration; Unicode before/inside/after removal, UTF-16 line/column and byte offsets, BOM bias, the exact seam inside a joined CRLF, and mixed physical source newlines. Strict mismatches/invalid bytes/unsupported encodings refuse at the documented boundary. |
| TD16 | Original and final bounds | At/over 8,388,608-byte originals including BOM in supported encodings; candidate exact original-minus-full-instruction length. Oversized original refuses even when removal would fit; no overflow or unbounded partial allocation. |
| TD17 | Static/resource coverage | Dependency/package/schema/type/component/static/use-when/shadow/extension and unsupported language contexts refuse before execution/acquisition. Resolver/extension instrumentation proves no ambient resource access; public inspection limits remain separate. |
| TD18 | Original/candidate validity | Invalid original cannot be repaired by removing its invalid instruction. Changed candidate independently inspected and restricted-validated; unproved/invalid candidates produce no authority. |
| TD19 | Cancellation and exclusivity | Pre-cancelled and deterministic traversal/copy/validation/map/pre-return cancellation gives new typed Cancelled without target/candidate. Legacy value-of throwing behavior unchanged; success/refusal exclusive and no NoChange outcome. |
| TD20 | Immutability/concurrency | Defensive exports and frozen list/map/fragment refs, isolated concurrent proposals against one owner, foreign-target and repeated old-owner controls; no mutation or consumer current-revision illusion. |
| TD21 | Intentional output behavior | Nonempty deletion has independent changed expected output; empty/self-closing may preserve runtime output but still changes source and requires candidate/review/history. No transformation runs in proposal and no output-equivalence gate is imposed. |
| TD22 | Composition and compatibility | Imported/inserted/replaced text then delete; fresh candidate ports and subsequent operations. Existing value-of/text insertion, value-of deletion, body replacement, literal elements and expression behavior/defaults/enums/binary contracts unchanged. |
| TD23 | Consumer adapter and complete review | Separate compatible capability/opaque port; old-package adapter safely unavailable. Frozen whole instruction/logical+lexical payload, exact edit, R/M/F/D/parent evidence; bounded full review refuses oversized evidence without truncation or consumer XML parsing. |
| TD24 | Session, permission and overlap | Current owner/source/inspection/revision/license/cancellation/overlap checks around async work and final Apply. Source/intent/policy changes invalidate review; cancel/deferred close/retry never publish unauthorized source. |
| TD25 | Atomic Apply/history/navigation | One explicit atomic source-owner step, mapped parent selection and fresh graph/outline inspection. Exact-byte undo/redo under new revisions; stale preview/validation/export becomes historical. Precommit cancellation retains source; committed late cancellation reports success. |
| TD26 | Real worker/export/reopen | Separate hand-written changed and output-unchanged fixture expectations; validation, ExactBytes worker preview, restricted new-file export/receipt/hash and independent destination reopen/inspect/validate/run across four encodings. No local probe substitutes for this consumer gate. |
| TD27 | Native observations | Human instruction/payload review, merge review, parent navigation, history/cancel/retry, validation/preview/export/reopen and original/export hash checks. Record actual variants/platform/accessibility observations and unknowns, preserving original receipts. |
| TD28 | Delivery separation | Source full solution + LS, exact-head CI, immutable head/merge PackageReference-only consumers, QT3 31,142/0/679 and qt4 8,278/0/1,894; independent Braid implementation review, later signed public delivery/adoption and native acceptance remain separate gates. |

Consumer-only TD23-TD27 and consumer malformed-evidence verification cannot be certified by source/unit tests. A baseline observation of a self-closing or preserved/mixed shape is not text-deletion eligibility or acceptance. Preserve initial failures, fixture/harness corrections, exact toolchain/revision, public provenance and counts separately; overlapping source/package/consumer checks are not additive unique coverage.

Design review must explicitly confirm self-closing inclusion, the nullable original body span, complete one/two-node removal, map-plus-merge partitions, joined-run normalization ownership, conservative mixed/preserved boundaries and new classified cancellation versus unchanged legacy throwing behavior. A no-blocking design review still needs separate user implementation authorization. No version, new capability or engine release is reserved here.
