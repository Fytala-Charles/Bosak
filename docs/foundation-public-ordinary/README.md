# Public ordinary-source facade

3 November 2026. Source **1.45.0** promotes the accepted XPath session/lifetime declarations and their required provider contract graph. [Consumer guide](GUIDE.md), [adoption basis](SPEC-BASIS.md), [scope/status](STATUS.json), [acceptance](ACCEPTANCE.json).

## Implemented behavior

The initial `bosak-ordinary-string-boolean-v1` profile compiles ordinary source navigation and string/boolean queries over trusted host input membership. Actual owner admissions cover getter access and raw callback/task completion. Descriptor capture occurs under the owner lease; cancellation reaches both owner/input availability. Existing qualified runtime admission, rollback, close and open/closed drain behavior is reused.

The compiler freezes options before validating a conservative AST profile. Numeric literals refuse before parsing; numeric inputs, arithmetic and other unavailable channels cannot bypass numeric limits. Assessor/origin/compatibility/typed-read/construction paths return explicit Unsupported without provider calls. This profile has no schema cache or typed enumeration. It provides no hard CPU/graph-size budget or actual provider validation.
