# Exact terminating division adoption — 4 November 2026

Recorded before source edits; implementation base 80dd99cb / source 1.50.0. Adopt the finite Core policy at [policy packet](../foundation-decimal-division-policy/POLICY.md), committed at 80dd99cb, and immutable [XPath REC-xpath-31-20170321](https://www.w3.org/TR/2017/REC-xpath-31-20170321/) section 3.5 and [F&O REC-xpath-functions-31-20170321](https://www.w3.org/TR/2017/REC-xpath-functions-31-20170321/) sections 4.2 and 4.2.4. Preserve prior XSD representation adoption; no later draft/erratum adopted. Historical policy/model evidence stays sealed.

Implement primitive integer/decimal exact terminating div only. Every successful result is Decimal. GCD reduction and cancellation of coefficient factors 2/5 against wide scale arithmetic precede result growth. Nonterminating reduced denominators explicitly refuse with NotSupportedException; this is an intentional unsupported subset, not the standard's required answer for general decimal division. No rounding, double fallback, rational carrier or rounding-mode API is introduced. Supplied quotas precede zero/nontermination/result checks; zero errors retain DivideByZeroException carrying FOAR0001, not complete standardized error-graph integration.

Use bounded chunk factor removal and growth, raw availability checks between chunks and before/after GCD/primitives, and preflight coefficient products before allocation. Guard thresholds use at most digit capacity plus one and only near actual operand width. Huge caller limits alone must not cause huge thresholds; extreme scale differences must not produce unchecked powers. Individual BigInteger primitives have no hard cancellation/latency bound.

Source feature 1.51.0. Plans containing div select bosak-exact-division-v4 / bosak-exact-division-static-v4, binding divisionPolicy=exact-terminating and divisionAlgorithm=gcd-factor-chunks-v1 with supplied digit/scale and derived output bounds. Existing v1/v2/v3 descriptors remain byte-for-byte selected for their old expressions. No public metadata change. Preserve old negative controls through equivalent unsupported syntax and positive new coverage. Qualify exact rational identities, scale/capacity/cost and runtime ownership/lifetime behavior, full solution and frozen gates before completion. Wider rounded division, schema/all-host/native/migration acceptance, C45/freeze and publication remain pending.
