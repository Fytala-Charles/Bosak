# W1-A immutable adoption basis

3 November 2026, recorded before source edits. Adopt the dated [XPath 3.1 Recommendation REC-xpath-31-20170321](https://www.w3.org/TR/2017/REC-xpath-31-20170321/), sections 2.1.1 (static context), 2.1.2 (dynamic context), 2.2.1 (data model generation) and 2.2.3.1 (static analysis) and 2.2.3.2 (dynamic evaluation). Adopt the dated [XDM 3.1 Recommendation REC-xpath-datamodel-31-20170321](https://www.w3.org/TR/2017/REC-xpath-datamodel-31-20170321/), sections 2.3 (node identity), 2.7 (schema information), 3.2 (construction from an infoset), and 6 (nodes). These dated sources were inspected before implementation; later errata/editor drafts are not adopted by this step.

Host admission/revocation/ownership are Bosak policy, not W3C language semantics. Exact basis: Core scoped R2 closure at commit 42628400 and proposal ff475d712f6ef6aa5033113cc39afb887ae4cbad24705098c5c9cb2097641688, decisions D01/D04/D05/D11/D12/D13, Schema v2 O1 ordinary-source distinction and XmlDb O1/O4. Lifetime extraction reuses the existing scalar snapshot primitive rather than weakening its issuer/type/provenance checks. Ordinary input composition has no issuer or assessment; explicit supplied origins refuse until the optional association layer is implemented.

Implement the internal neutral W1-A admission/runtime path and an internal compiled XPath factory first. Public declarations, optional schema-advisor composition and XQuery/XSLT host integration follow dependent slices; no throwing public placeholders. Trusted input adapters provide live membership before purported node getters; exactly one admitted owner is required. Resources are already host-acquired. Close revokes guarded access; raw operation leases defer release; Drain observes completed release, preserving original errors. No eager graph copying/scanning, fabricated provenance, required IXdmNode disposal or new native adapter.

Deliberately bounded opt-in profile: existing immutable static capture and bounded dynamic inputs, closed external resource policy, explicit finite snapshot/binding/namespace limits, flat copied atomic results only, no schema-marked values, arbitrary external services, lazy results or new owner budgets. Legacy APIs and existing typed paths retain their behavior. Shared lifetime extraction must pass typed regressions. W1-09/10 remain W1-D; W1-18 remains R4. Source version advances to 1.43.0 for this internal feature; release tag/version selection remains separate.

Review correction: the initial section label for dynamic evaluation was corrected to 2.2.3.2; the dated immutable source and adopted processing-model scope are unchanged.
