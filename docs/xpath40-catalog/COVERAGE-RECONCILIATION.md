## AC-03 - evidence inventory and approved decision

The original criterion required every entry's Known Uses to cite qt4tests gate sets. That original wording is retained here as history; the owner approved the applicable-evidence amendment below on 22 October 2026. Of 71 Known Uses sections, **25 literally mention at least one name in the current 218-member GatedSets** and **46 do not**. The scanner checks names, not whether every cited set covers each contract. A passing set may cover only part of an entry; an entry without a literal set name may still have named unit, XSLT or refusal tests. The JSON makes these distinctions inspectable. Missing literal names therefore do not mean 46 untested features.

**Approved acceptance wording - owner decision, 22 October 2026:**

> Each entry's Known Uses identifies its applicable executable evidence. Implemented XPath contracts name the relevant current qt4tests gate sets where available, or explicitly record an unassigned set together with named engine tests. XSLT-only contracts name XSLT runner/unit tests and runnable public examples, explicitly stating that a XPath gate is not applicable. Deferred, rejected and out-of-scope decisions cite disposition evidence plus a versioned refusal test or a supported alternative where executable. Sample Code remains verified verbatim or pinned to a named test; worked examples retain input, context, expected output, compatibility and a meaningful edge case. A missing gate is never presented as conformance, and unsupported syntax is not implemented solely to create gate evidence.

The owner selected the applicable-evidence policy. The alternative of retaining a blanket qt4tests-only requirement was not selected. The REQ-126 criterion in FEATURE_REQUESTS.md is amended accordingly. This approval changes the evidence policy; it does not certify any entry, close AC-03, implement deferred syntax or promote a gate. All 71 entries still require an evidence pass under the approved rule.
