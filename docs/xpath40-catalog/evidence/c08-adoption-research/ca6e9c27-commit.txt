* feat(xpath40): REQ-118 4.0-S6b — structural record types + 'but with'

XPath 4.0 §3.2.10 structural record types behind the xpath40 gate
(XPST0003 in 3.1 mode): record(*), record(), record(field as
SequenceType?, ...) with NCName or string-literal field names, omitted
field type = item()*, duplicate field names XPST0021. A record is a map
with a record-type annotation (Issue 1979/PR 2566) — first XDM change
of the REQ-118 wave: XdmMap.RecordType + WithRecordType, new
XdmRecordType/XdmRecordField in Core/Xdm. Instance-of is structural with
exact entry count (plain maps never match; per-field recursive matching
gives covariant field subtyping). Coercion (§3.4.2 rule 10): missing
fields become () entries (XPTY0004 when the field type requires a
value), surplus keys XPTY0004, values coerced recursively, entries in
declaration order. Cast (§4.19.2.7) differs: keep-or-cast values
(FORG0001), surplus keys discarded, record(*) is an assertion.
Lookup (§4.15.3): ? keys and record-as-function calls field-check
(XPTY0004); map:* stays field-blind. 'but with' (§4.15.4) = use-last
merge + re-coercion to the LHS annotation (plain-map LHS XPTY0004);
BinaryOperator.ButWith reuses BinaryExpressionNode + new IrOpCode.ButWith
— no new AST node.
