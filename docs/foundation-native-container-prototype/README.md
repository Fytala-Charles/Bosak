# Native decimal container prototype — TA-46

An isolated provider adapter now transports **actual native assessed decimal values through the public 1.81.0 typed-container and scalar execution APIs**. The final Release build has zero warnings/errors and **19 controls pass**. The earlier 16-case run overlaps these cases. Core production, native Schema source and package pins are unchanged.

The adapter is test-only code in [prototype](prototype/NativeContainerAdapter.cs), compiled against the exact qualified nine-engine output closure and the TA-44 native source-lane Schema DLL. It implements provider-owned component handles, exact advisor binding, issued origin/container checks and a version-guarded captured input. It keeps root no-typed-value and omitted children out of the decimal container collection. It does not cast or promote private legacy evidence.

[Tests](prototype/NativeContainerTests.cs) exercise actual native assessment before reissuance, complete container metadata and ordered decimal payloads, public scalar evaluation, foreign input/advisor/component refusal, native copy reissuance, caller mutation isolation, cancellation, input revocation and raw view/provenance/cursor expiry. A copied plain decimal remains usable after raw completion. Forged containers refuse before their getters execute.

`XDocumentNode` exposes its underlying XML. The prototype therefore checks its captured serialization before provider reads and permanently revokes a changed input. This is a correctness guard for an isolated serial prototype, not a concurrent mutation protocol or qualified performance strategy. Caller mutation during capture/operation is outside the profile. Input membership currently admits only its exact root object; full descendant projection is deliberately absent.

Each reissued input has fresh public source/snapshot/origin bindings. A native assessment copy retains native component/assessment state, but does not automatically inherit public source identity or compatibility. No process-global issuance registry is introduced. Provider-owned immutable metadata may outlive a raw callback; the engine-returned borrowed views expire with that callback.

**Scope remains bounded.** The public `Assess` request returns Unsupported with no validated root; no original-node facts channel is exposed. This qualifies a preassessed decimal container vertical slice, not a public whole-document Schema provider. Lax/type requests, constructor/derivation/substitution/closure operations, lists/unions/nil, compatibility and persistence remain unsupported or separate work. Names and GUIDs never grant authority. No Core API addition was needed for this slice.
