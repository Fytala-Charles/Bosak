# Eleven-kind complete-container reads in development sources

The existing ordinary and compatible `ReadTypedContainer(snapshot, providerValue)` member now accepts complete containers of eleven publicly constructible atomic kinds: String, Integer, Decimal, Boolean, Double, Float, Date, Time, DateTime, Duration and QName. Use the matching admitted snapshot and the provider-issued source container inside its exact raw callback. Inspect result.Kind before reading Value. See the [ordinary guide](../foundation-public-container/GUIDE.md) and [compatible lifetime guide](../foundation-compatible-container/GUIDE.md) for callback structure; their historical four-family limitation is superseded by this guide.

Payloads are copied as existing plain carriers. Floating stored bits, including NaN/infinities/negative zero, remain exact. QName includes LocalName, NamespaceUri and Prefix even though QName semantic equality ignores prefix. Temporal kind, extended year, all fields and both recorded timezone flags survive without conversion to DateTimeOffset. Duration lexical text and all schema/user tags remain unchanged. This does not add precision missing from the carrier or make every extended-year arithmetic operation available.

Null String/Duration payloads and QName with null/empty local name or null namespace/prefix reject the complete read. Empty namespace URI and prefix strings are allowed. The boundary does not parse lexical text or independently validate NCNames, calendar values, XML Schema facets or annotations. The issuing provider remains responsible for assessment correctness and immutable/version-guarded issuance. Type-name tags are descriptive; separate governing/declared/selected handles and origins still require exact ownership.

URI/hexBinary/base64Binary public lexical carriers remain annotated Strings. The separate Uri/Binary enum kinds have no public factories and remain unsupported by this boundary pending PV-T06 disposition. No byte buffer, new public factory or resource lifetime is inferred. Node/map/array/function/default/already-marked/evidence-free cells remain invalid; atom/digit/scale limits apply before complete delivery. These limits do not bound text length or aggregate caller-retained output memory.

Empty and singleton list boundaries, union member order and original metadata remain preserved. Every metadata/evidence/cursor access stays raw borrowed; compatible accesses retain the serialized paired-provider window and exact established proof. Copied immutable plain values survive expiry, while TypeEvidence expires before provider callbacks. No independent lease, scalar registry entry, new authority or old-view revival is introduced. Existing scalar identity/evaluation, numeric operations, construction and other profiles retain their previous scope. Native/provider/budget/owner/freeze acceptance and broader persistence/nil/no-value routes remain pending. Development1.81.0 is not a selected publication version.
