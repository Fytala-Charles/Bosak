## 4. W3C Conformance Skip Mapping (confirmed 2026-10-27)

The core harness (REQ-112, `tests/Bosak.Xslt.Conformance/Program.cs`) skips XSD 1.1 tests via three triggers: (1) the principal stylesheet inlines `xs:assert`/`xs:alternative`, (2) an environment schema pins `xsd-version != "1.0"`, (3) an environment schema file's raw text matches `xs:assert`/`xs:alternative` (books.xsd is wrongly pinned `1.0`, so pins alone are not authoritative). **Harness-confirmed on current core main: 30 skips** (run per affected test set in `--schema-aware` mode, 2026-10-27; a faithful static port of the same rules found 31 — the extra one, `catalog-005b`, is skipped earlier by another harness mechanism; `validation-1301` declares its `xs:alternative` inline but has no principal stylesheet file, so it skips before the inline check). The REQ-112-era note of "28" was the FAIL→SKIP *delta* measured 2026-09-30; the current authoritative count is **30**.

| Skip family | Confirmed IDs | Closing phase |
|-------------|---------------|---------------|
| `xs:assert` — streaming source-document (`books.xsd`) | `stream-101`…`stream-109`, `non-stream-101`…`non-stream-109` (18) | **S2** |
| `xs:assert` — merge (`books.xsd`) | `merge-049`…`merge-054` (6) | **S2** |
| `xs:assert` — misc | `accumulator-073`, `si-apply-templates-007`, `si-apply-templates-012` (3) | **S2** |
| `xsd-version="1.1"` pins | `catalog-005`, `catalog-009`, `strip-space-009` (3) | **S2** (assert-bearing environments) |

Notes: all 30 run through environments that carry assertion-bearing schemas (`books.xsd` uses `xs:assert`); the `xs:alternative` family (`validation-1301` et al.) is currently unreachable in the harness for structural reasons and must be exercised via add-on acceptance tests until S4. Simple-type `xs:assertion` cases (S3) are not represented in the XSLT 3.0 catalog's skip set; they will be covered by add-on facet tests plus the W3C XSD 1.1 test suite during S3.
