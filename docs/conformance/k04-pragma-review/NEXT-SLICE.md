# K04-C37 — Implement ignored-pragma fallback

28 October 2026. C36 does not qualify admission: its isolated full QT3 gate has 47 failures. Keep the normal pragma refusal and exact **31,340/0/481** baseline during implementation.

1. Record explicit immutable semantic adoption of XQuery 3.1 REC-20170321 §3.22 and the relevant lexical/ValueExpr grammar before implementation. Preserve C36's 60 originals, all assertions/resources, current errors and independent exact-XQ10 exclusions. Choose and document the implementation-defined recognized pragma namespace set; the bounded recommendation is an empty set, so every well-formed pragma is ignored and its associated expression supplies fallback. This is a recommendation, not an accepted policy yet.
2. Add XQuery-only raw pragma lexing: recognize `(#`, optional XML whitespace, EQName and required separating whitespace for nonempty contents; consume raw contents to the first `#)`. Do not interpret quotes, comment-like text or entity-like text as ordinary expression syntax inside pragma contents. Reject missing names/delimiters and invalid lexical spacing. Preserve XPath and 4.0 QName-literal behavior outside this grammar.
3. Parse one or more pragmas followed by an associated expression at ValueExpr precedence. Resolve prefixed names using the declaring static namespace context (XPST0081); unprefixed and empty-URI names are ignored under 3.1. If all pragmas are ignored and the associated expression is absent, raise XQST0079. Parse/compile the associated expression and preserve its static and dynamic errors. Do not introduce a handler API, claim a recognized pragma or silently treat unsupported recognized content as valid.
4. Cover happy/edge public API cases: prefixed/EQName/no-namespace names, multiple pragmas, raw delimiters and unmatched quote/comment content, comments outside pragmas, missing/empty fallback, namespace scope in library functions/globals/closures, malformed spacing and delimiters, parenthesized versus bare postfix/path use, and associated-expression errors. Include XPath/profile compatibility regressions and immutable module-scope behavior. New feature versioning applies; no release is authorized.
5. Re-run all 60 unchanged originals through actual environment/module/executor machinery with isolated routing, all public and lexical controls, full solution tests and both complete normal gates. Retain the two exact-XQ10 exclusions and independently tracked schema errors. Avoid weakening assertions or changing fixtures to obtain green results.
6. Only after the semantic implementation is qualified, perform a separate full-catalog routing admission review. Reconcile every affected case, retained skip name/reason and compatibility cohort; present any concrete baseline proposal for owner approval. Bosak.Schema owns XSD 1.1 and ADR-006/REQ-139 remains separate. No release, upstream submission or Braid change is included.
