## Proposed public surface

| Surface | Proposed contract |
|---|---|
| `AuthoringCapabilities.SupportsLiteralAttributeLifecycle` | True only when Create, Update and Delete, shared evidence and compatibility gates are implemented together. Does not enable AVT slot replacement. |
| `MaxLiteralAttributeSourceBytes`, `LiteralAttributeSupportedEncodings` | Original and actual final each at most 8,388,608 physical bytes, including BOM. Immutable UTF-8 / UTF-16LE / UTF-16BE list; four physical variants as below. |
| `AuthoringSnapshot.GetLiteralAttributeCreationTarget(owner, cancellationToken)` | Owned actual literal element descriptor to opaque `AuthoringLiteralAttributeCreationTarget` or typed failure. Creation authority is distinct from existing-attribute authority. |
| `GetLiteralAttributeUpdateTarget(owner, attribute, cancellationToken)` | Owned actual element and actual attribute descriptor to opaque operation-specific `AuthoringLiteralAttributeUpdateTarget` or failure. |
| `GetLiteralAttributeDeletionTarget(owner, attribute, cancellationToken)` | Same ownership/constancy checks, separate `AuthoringLiteralAttributeDeletionTarget`. Neither target authorizes another operation. |
| `AuthoringLiteralAttributeCreationProposal(target, localName, value)` | Immutable absent-name Create intent. Name is an XML NCName; value is logical literal text. No caller range/layout. |
| `AuthoringLiteralAttributeUpdateProposal(target, value)` | Immutable fixed-name Update intent; no rename or missing-target creation. |
| `AuthoringLiteralAttributeDeletionProposal(target)` | Immutable Delete intent with no name/value/layout input. |
| `ProposeLiteralAttributeCreation/Update/Deletion(proposal, cancellationToken)` | Separate operation result types. Create/Delete: exclusive Candidate or Failure. Update: exclusive Changed Candidate, NoChange receipt, or Failure, with explicit outcome enum. |
| `AuthoringLiteralAttributeCandidate` | Shared immutable evidence below, with explicit `Operation` (Create/Update/Delete). Separate result/proposal types retain intent; candidate evidence alone is never proposal authority. |
| `AuthoringLiteralAttributeUpdateNoChange` | InputSnapshot, owned Update target, ModuleUri, unchanged logical value. No Snapshot candidate, edit, candidate attribute, export or Apply authority. |
| `AuthoringLiteralAttributeFailure` / `FailureKind` | Shared typed refusals with Message, optional Code/Range, ModuleUri; operation supplied by the calling result. Existing failure enums are unchanged. |

Discovery results contain exactly Target or Failure. Null reference arguments throw `ArgumentNullException`. All new discovery/proposal cancellation is classified `Cancelled`; legacy throwing behavior stays unchanged. Target constructors are nonpublic. Targets retain private exact snapshot/source/static identity, actual owner descriptor and, for Update/Delete, actual attribute descriptor and proven constant logical value. A copied attribute name/index/range, equal-byte foreign snapshot or reused integer node ID never authorizes an edit. Recheck all authority during proposal, including discovery assumptions.

Targets expose Owner, ModuleUri, OriginalOpeningTagRange and IsSelfClosing; existing-attribute targets additionally expose Attribute, AttributeRange, ValueRange, QuoteDelimiter and LogicalValue. OpeningTagRange includes `<` through `>` (including `/` for self-closing syntax). AttributeRange is the name through closing quote, excluding adjacent trivia; ValueRange excludes quotes and may be empty. These are validated retained-source ranges, not permission to submit offsets. There is no mutable source-owner handle or public constructor for forged evidence.

## First supported profile

Support a **no-namespace literal result element** beneath a top-level template through a literal-result-only ancestor chain in a dependency-free principal explicit XSLT 3.0/4.0 stylesheet/transform. An imported document supplied as the principal source and a previously authored candidate may qualify; included/imported dependency modules do not. Support paired and self-closing owners without changing their spelling. A qualified owner is explicitly refused in this first profile, including an unprefixed owner under a nonempty default namespace. XSLT instruction aliases/default XSLT namespace syntax are recognized by expanded name, never by the string `xsl`.

Only unqualified no-namespace ordinary result attributes are addressed. Validate names with XML 1.0 NCName rules, exact case and Unicode spelling; reject empty, colon/prefix, invalid characters and reserved exact `xmlns`. `XMLNS` is a distinct ordinary NCName where otherwise valid. Reject namespace declarations, xml:* and XSLT control attributes, qualified attributes, `xsl:attribute`, namespace fixup/control edits and rename. Duplicate Create uses expanded name and refuses even if the existing attribute is dynamic or otherwise unsupported. A null/foreign descriptor or attribute not actually belonging to the supplied owner cannot fall back to a lookup by name.

Whole-module coverage is required independently of target eligibility. Reuse the established restricted authoring validation only where its guarantees hold, adding literal-attribute semantic coverage. Refuse dependencies, packages/schema acquisition, DTD/entity declarations, extension contexts, static evaluation/use-when/shadow preprocessing, unsupported effective versions, type/component annotations and attribute sets before compilation or resource acquisition. Deny unsupported expanded text and unproved expression/pattern/function contexts. Every existing unqualified result attribute in the principal module must be engine-proven constant in this first profile; dynamic AVTs anywhere in that set refuse, not merely at the selected attribute. Namespace/control metadata survives only when explicitly covered by restricted validation. No arbitrary qualified result-attribute semantics are claimed; unsupported qualified result attributes refuse. Supported namespace declarations and covered xml:space metadata are retained unchanged.

Attribute-only editing does not remove or insert graph children. Ordinary literal text, whitespace, comments/PIs, inherited xml:space=preserve/default and supported descendant instructions may remain when complete restricted coverage and unchanged-node proof are available. Do not import deletion's surrounding-text merge exclusions merely because its helper exists. CDATA/expanded-text or other ambiguous descriptor coverage may be refused explicitly as UnsupportedCoverage. NoChange is also subject to original validity and complete coverage. An invalid original module cannot be repaired by Update/Delete or bypassed through equal intent. This family must not narrow any existing operation's accepted profile.

## Logical values and constant proof

Values are exact XML 1.0 Unicode scalar strings; preserve empty, spaces, tab, CR, LF, CRLF, supplementary and decomposed forms. Reject invalid XML characters and lone surrogates without replacement. No trimming, case folding, normalization, XPath evaluation or sample-output equality. `LogicalValue` means the constant result-attribute value after XML attribute normalization/reference expansion **and** AVT literal-brace interpretation. `AuthoringAttributeDescriptor.ExpandedValue` is only XML-expanded metadata and is not this final value when escaped braces are present.

The engine must parse the XML-expanded attribute value using its AVT semantics and prove it contains literal segments only, including valid doubled braces. SlotKind Plain/Avt, raw brace scanning and absence of a raw `{` are insufficient. Character references can introduce braces before AVT processing: `&#123;name&#125;` is dynamic, while `&#123;&#123;name&#125;&#125;` may prove constant `{name}`. Unmatched braces or invalid AVTs make the original invalid; unsupported/unproven forms refuse. Only predefined XML entities and legal character references are supported; do not resolve a DTD or general entity.

Emission operates on logical scalars: double each literal `{` and `}` for AVT semantics, then XML-escape ampersand, `<` and the retained quote delimiter. Encode tab/CR/LF as `&#x9;`, `&#xD;`, `&#xA;` to preserve exact logical whitespace through XML attribute normalization. Other valid scalars use the retained source encoding; `>` may remain literal. Create uses double quotes; Update escapes its retained single or double delimiter and never changes it. User input is never treated as pre-escaped XML: logical `&amp;` must remain those five output characters, not become `&`. Reinspect/reprove the candidate and compare its addressed logical value ordinally with the requested value.

Update compares the proven old logical value with validated intent using ordinal equality, **after** all original authority/coverage/encoding/bound/validity checks and before computing hypothetical canonical output size. Equal intent returns only NoChange, preserving every original byte, quote/reference/brace spelling and snapshot. A canonically emitted spelling that would exceed the bound does not invalidate an otherwise valid equal-intent original. Normalization-distinct strings remain distinct. NoChange is not candidate success and creates no source revision/history or renewed validation evidence.

## Exact source edits and bounds

Let original bytes be B and the proven affected range [a,b). Candidate C is exactly B[0:a] + encoded replacement + B[b:length(B)]. Exactly one complete `AuthoringInsertionSourceEdit` links the actual original/candidate range; the existing edit type is reused only with its established byte/coordinate meaning.

| Operation | Edit footprint |
|---|---|
| Create | Insert one ASCII space plus `name="escaped-value"` immediately after the lexical owner element name, before all pre-existing opening-tag trivia/attributes. OriginalRange is the real zero-length boundary; CandidateRange covers separator plus token. Existing attribute order and all bytes remain unchanged; the new attribute is first in candidate order. |
| Update | Replace exactly the existing retained ValueRange inside the original quotes. OriginalRange/CandidateRange may be zero-length for empty values. Name, equality spacing, delimiters and all outside bytes remain unchanged. |
| Delete | Remove exactly AttributeRange from name through closing quote. CandidateRange is the real zero-length seam. Retain all surrounding whitespace, including redundant spaces, and paired/self-closing punctuation/body. |

Create's inserted token range excludes its added separator and is exposed separately from the complete edit. Retained descriptor FullRange currently excludes trivia; proof uses the scanner and exposes the operation's AttributeRange explicitly rather than assuming every future descriptor representation has that footprint. Update/Delete never trim source, remove namespaces, reorder siblings or regenerate an opening tag. Existing attributes remain in their relative order, with new/removed addressed attribute accounted for. Owner full extent, opening-tag extent and containing ancestors may change lengths; their coordinates translate by the proven splice. All descendants retain exact source bytes and logical metadata.

Replay the single edit to reproduce defensive ExportSource exactly; every unchanged gap must be byte-identical. Each source owns its own strict byte/UTF-16 line/column map, including BOM bias, supplementary characters, reference spelling and physical CR/LF. Range translation uses offsets and a specified boundary affinity around the edit, then each map computes positions; do not subtract byte lengths from columns. Empty ranges are evidence, not fabricated nodes or attributes.

Original and actual final each independently satisfy 8,388,608 physical bytes including BOM; reject an oversized original even for shrink/Delete/equal Update. Checked byte counting precedes allocation and accounts for escaping, separator, quote and encoding expansion. Retain UTF-8 without/with BOM, UTF-16LE/BE with BOM and matching declarations, XML 1.0 only. No conversion or declaration rewrite; invalid encoding/declaration pairs refuse at inspection or operation boundary as documented. Do not allocate unbounded escaped intermediates before checking bounds; count/copy cooperatively with cancellation.

## Complete candidate and provenance

Every Changed candidate exposes InputSnapshot, fresh Snapshot, ModuleUri, Operation, actual OriginalOwner/CandidateOwner, OriginalOpeningTagRange/CandidateOpeningTagRange, AddressedName (expanded and lexical), nullable OriginalAttribute/CandidateAttribute, nullable original/candidate AttributeRange and ValueRange, nullable OriginalLogicalValue/CandidateLogicalValue, SourceEdits, complete NodeCorrespondence, per-owner AttributeCorrespondence and defensive ExportSource(). Absence is explicit: empty string/span is never absence. Create has no old attribute/value; Delete has no new attribute/value. Update has both. Candidate attributes are actual members of CandidateOwner.Attributes.

NodeCorrespondence is an immutable `IReadOnlyDictionary<AuthoringNodeDescriptor, AuthoringNodeDescriptor>` using actual snapshot references. It is a total bijection over all original/candidate principal graph descriptors, with no created/removed graph nodes and no text split/merge. Preserve kinds, lexical/expanded names, parent/ordered children, text/comment/PI values and module/document ownership, and strict translated ranges. Attribute-only edits cannot silently reuse deletion's merge groups or invent attribute child IDs. CandidateOwner is exactly the mapped OriginalOwner. Module URI/declaration/physical representation are unchanged.

AttributeCorrespondence is a complete immutable collection of per-owner records, each naming actual OriginalOwner/CandidateOwner and an injective ordinary attribute-reference map. Include every actual descriptor in every element's Attributes collection, including namespace/control metadata. An explicit addressed pair/absence on the edited owner is excluded from this ordinary map:

- Create: all old attributes are ordinary survivors; precisely one actual new attribute is addressed, with no old counterpart.
- Update: precisely the selected old/new pair is addressed; every other actual attribute is an ordinary survivor.
- Delete: precisely the selected old attribute is addressed and removed; every candidate attribute has an ordinary old counterpart.

For other owners all attributes are ordinary survivors. The partitions must be complete, disjoint and injective; no missing/extra/foreign/duplicate attribute is excused by equal name/value. Ordinary survivors preserve name/prefix/namespace/local name, SlotKind, RawLiteral, ExpandedValue, lexical order and translated FullRange/ValueRange, with compatible captured context under the same restricted profile. Addressed Update preserves name, equality syntax and quote delimiter; only value bytes and resulting logical/XML-expanded/slot metadata may change. Do not require the updated SlotKind to remain equal when escaping introduces braces. Graph node IDs remain snapshot-scoped, not stable cross-source identity.

New selection is CandidateOwner plus actual CandidateAttribute and its ValueRange for Create/Update, including a real empty value span. Delete selects CandidateOwner and clears attribute/expression selection; the deletion seam does not become a fake attribute port. Subsequent operations rediscover fresh targets from the candidate. All collections/exports are immutable or defensively copied; parallel proposals against the same immutable snapshot have isolated results. Old snapshots remain valid on themselves; only Braid asserts current session/revision/license/history authority.

## Refusals, validation and cancellation

Proposed FailureKind values: CapabilityUnavailable, ForeignSnapshot, UnknownTarget, IneligibleOwner, IneligibleAttribute, InvalidName, InvalidValue, DuplicateAttribute, UnsupportedModule, UnsupportedProfile, UnsupportedCoverage, UnsupportedEncoding, SizeLimit, InvalidOriginal, InvalidCandidate, ResourceDenied, SourceAlignmentFailure, UnsupportedCorrespondence, Cancelled. Use UnknownTarget for absent owned selection where representable; an old/foreign descriptor is ForeignSnapshot, never a successful missing Delete. No public enum renumbering. Single-cause tests establish classifications; no universal ordering for multiple faults is promised.

Order: null/cancellation/identity; independent original bound and supported module/encoding/profile; lexical owner/attribute alignment and complete coverage including constancy; original restricted validation; validated logical input/name and Create absence; equal Update decision; checked exact emission; independent candidate inspection/validation; full source/node/attribute partition proof; final cancellation immediately before publishing Target/Candidate/NoChange. Discovery performs the checks applicable without proposed name/value. Proposal repeats authoritative checks. If cancellation is observed before return, return only Cancelled, without a partial target/candidate/NoChange. Parsing is not promised to be preemptive; observe cancellation around parsing, traversal, counting, encoding/copy and proof.

No proposal transforms a document or obtains ambient file/network/extension resources. Deny unsupported preprocessing before compilation; use deny-by-default resource authority for both validations. Unexpected engine defects remain distinguishable from user syntax failures, not caught and relabeled wholesale. Failure.Range, when supplied, belongs to input principal source; omit candidate-only offsets rather than publishing an unowned partial source. Refusal, NoChange and cancellation never mutate shared snapshots.

## Braid review, Apply and delivery gates

Braid uses separate opaque operation ports and frozen operation-specific review. Display exact logical old/new values separately from lexical source, complete affected opening tags, exact edit and complete node/attribute correspondence with source/engine/revision provenance. Changing operation, owner/attribute, name/value or source invalidates held review. NoChange has feedback with Apply disabled and no fabricated history/redo change. Oversized complete review/input refuses rather than truncates authority-bearing evidence; policy loss hides source-derived data.

Explicit Apply independently checks current session/source/inspection/port/revision/license/cancellation/overlap and complete frozen evidence at an atomic source-owner boundary. Each Changed operation creates one exact-byte history step with fresh navigation/inspection on undo/redo. Precommit refusal/cancellation preserves source and still-current retry authority; committed late cancellation reports success. Historical validation/preview/export receipts remain historical even when bytes recur.
