# Original-facts reader design

`IQueryNodeFactsIssuer` is an internal capability extending container issuance with original-facts issuance and the exact node/facts/original-input/origin tuple. Neutral source ownership remains independent of Schema authority. `Operation.RequireNodeOwner` requires membership and exactly one owner across the complete admitted source set, with the selected snapshot as that owner. Availability is checked after ownership callbacks, including false answers, before any node/fact property is read.

The reader accepts explicit facts; it does not fetch `ISchemaAnnotatedNode.OriginalSchemaFacts` or globally add schema fallbacks. It checks selected environment, exact original input/projection, original origin, current authority, fact issuance and full tuple before and after every fact property and outcome read. Required original governing type and optional declaration must be authority-owned. Governing type identity must agree with the subordinate typed container; original facts are not remapped to compatibility targets.

Explicit absence bypasses the typed-value getter and stays Absent. An owned Unsupported outcome stays Unsupported without reading Value. Supported requires a non-null container, checked through the complete TA-01 reader with original origin, atomic bounds and per-cell actual provenance. Invalid/NotFound/null outcomes refuse. Nilled plus absence, nilled non-elements and nonempty nilled typed results refuse as malformed facts. A non-nilled empty result remains distinct from absence; empty and singleton list shape is retained.

A guarded issuer wrapper rechecks original facts across subordinate container properties, iteration and disposal. Complete reads stage privately without registering scalars or creating a facts cache. The returned metadata view checks original tuple and governing/declaration ownership without getter replay; its typed container and atomic views additionally revalidate all captured cell types/provenance and limits. Raw completion revokes every view. The existing container reader preserves primary/cleanup AggregateException order and exactly-once enumeration cleanup.

This transient design introduces no retained-memory cache keyed by arbitrary nodes/facts and no reinterpretation of scalar-cache quotas. The first cost attribution identifies repeated ownership callbacks as the next optimization target. No callback is invoked under a facts registry lock because no such registry exists. Limits bound atom count and numeric payloads, not arbitrary provider work or graph traversal. Provider contracts require immutable issued facts; the engine does not reread their payload on every observation.

Public node-query grammar/descriptor, fn:nilled optional-Boolean mapping, FOTY0012 delivery, ordinary-node fallback, construction, compatibility and native adapters remain separate. Existing public source files and profiles are unchanged. The internal fixture is not native Schema qualification.
